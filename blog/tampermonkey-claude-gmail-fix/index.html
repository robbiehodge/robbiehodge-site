My Gmail Search Bar Broke. The Fix Was One Screenshot Away.

Published
October 19, 2026
Read Time
4 min read
Category
AI Tools · Productivity

I got a new ultrawide monitor last week. It’s great for everything except, apparently, Gmail. Something about the extra width crammed Gmail’s UI into a layout it wasn’t designed for. The sidebar expanded. The toolbar shifted. And the “Ask Gmail” search input — the one I use probably 40 times a day — shrank into something barely clickable.

But that wasn’t the only problem. Gmail’s header at that width was packed: Gemini buttons, a Studio link, Support icons, an Upgrade prompt. All fighting for space in the same toolbar. None of them things I use. All of them making it harder to get to the thing I actually needed.

I tried the obvious fixes. Zoom levels. Different browsers. Hard refresh. The layout issues persisted. So I decided to just ask Claude.

The Screenshot Approach

I took a screenshot of Gmail, dropped it into Claude, and said something like: “My Gmail header is cluttered and cramped at this width. Can you write a Tampermonkey script that hides the stuff I don’t use and widens the search bar?”

Claude identified the exact elements causing the clutter — Gemini, Studio, Support, the Upgrade button — and wrote a script that hides them on load and keeps them hidden as Gmail’s single-page app navigates. It also targeted the Ask Gmail input container and forced it to a usable 320px width.

The response included a complete Tampermonkey userscript — ready to paste, no modifications needed.

What is Tampermonkey?

It’s a browser extension that lets you run custom JavaScript on any website. You install it once, then you can add scripts that modify how pages look or behave. It’s one of the most useful power-user tools on the web — and you don’t need to write code to use it if Claude writes the scripts for you.

The Script

Here’s the exact script. Install Tampermonkey, open its dashboard, click “Create a new script,” paste this in, and save.

// ==UserScript==
// @name         Gmail Narrow Window Cleanup
// @namespace    robbie-gmail
// @version      1.2
// @description  Hides Gmail header clutter and widens Ask Gmail.
// @match        https://mail.google.com/*
// @grant        none
// ==/UserScript==

(function () {
    'use strict';

    function hideElement(el) {
        if (!el) return;
        el.style.setProperty('display', 'none', 'important');
    }

    function widenAskGmail() {
        const candidates = document.querySelectorAll(
            '[aria-label*="Ask Gmail"], input[placeholder*="Ask Gmail"], [role="search"]'
        );

        candidates.forEach(el => {
            let container =
                el.closest('form') ||
                el.closest('[role="search"]') ||
                el.parentElement;

            if (!container) return;

            container.style.setProperty('width', '320px', 'important');
            container.style.setProperty('min-width', '320px', 'important');
            container.style.setProperty('max-width', '320px', 'important');
            container.style.setProperty('flex', '0 0 320px', 'important');
        });
    }

    function cleanupGmail() {
        // Hide Help / Support
        document.querySelectorAll(
            '[aria-label="Support"], [aria-label*="Help"]'
        ).forEach(hideElement);

        // Hide Gemini
        document.querySelectorAll(
            '[aria-label*="Gemini"], [data-tooltip*="Gemini"], [title*="Gemini"]'
        ).forEach(hideElement);

        // Hide Studio
        document.querySelectorAll(
            '[aria-label*="Studio"], [data-tooltip*="Studio"], [title*="Studio"]'
        ).forEach(hideElement);

        // Hide Upgrade
        document.querySelectorAll('a, button, div, span').forEach(el => {
            const text = (el.innerText || '').trim();
            if (text === 'Upgrade') hideElement(el);
        });

        widenAskGmail();
    }

    cleanupGmail();

    const observer = new MutationObserver(() => {
        cleanupGmail();
    });

    observer.observe(document.documentElement, {
        childList: true,
        subtree: true
    });

})();

The Fix, Step by Step

Here’s exactly what I did:

  1. Installed Tampermonkey in Chrome (took about 45 seconds)
  2. Opened the Tampermonkey dashboard and clicked “Create a new script”
  3. Pasted the script above, replacing the default placeholder
  4. Saved it and reloaded Gmail

The result: Gemini, Studio, Support, and the Upgrade button — gone. Ask Gmail — properly sized. The header went from cluttered to clean in under two minutes.

What the script does, specifically: It hides the Gemini, Studio, Help/Support, and Upgrade UI elements in Gmail’s header. It then finds the Ask Gmail search container and forces it to 320px wide. A MutationObserver re-runs the cleanup whenever Gmail’s DOM updates, so it survives navigation between inbox, sent, and labels.

Why This Matters

Six months ago, fixing a layout problem in a third-party web app required either technical knowledge to inspect the DOM and write CSS overrides yourself, or waiting for the vendor to patch it (Gmail still hasn’t, by the way).

Now it requires a screenshot and a sentence.

I’ve since used the same approach to:

  • Remove an annoying promotional banner from a SaaS tool I use daily
  • Fix a date picker that rendered off-screen in a project management app
  • Add keyboard shortcuts to a web app that didn’t have them
  • Auto-collapse a sidebar that kept reopening every time I navigated

None of these required me to write a single line of code. I described the problem, shared a screenshot when useful, and Claude provided a ready-to-run Tampermonkey script each time.

The Broader Shift

There’s a version of this story that’s just “AI is useful for debugging.” But I think it’s actually about something more specific: AI collapses the distance between identifying a problem and fixing it for people who aren’t developers.

The traditional path was: notice problem → Google it → find forum thread → realize no solution exists → give up or pay someone. The new path is: notice problem → describe it to Claude → paste the script → done.

The screenshot was the interface. The Tampermonkey script was the output. The whole thing took less time than writing this paragraph.
